# 後台操作手冊

後台網址：<https://lijie5867.com/admin/>

## 登入

1. 輸入已授權的管理信箱。
2. 按「寄送登入連結」。
3. 到信箱開啟 Supabase 寄出的連結。
4. 回到後台，確認出現「網站內容管理」。

登入連結具有時效。連結失效時，回到後台重新寄送即可。

## 修改頁面

1. 在「網站頁面」分頁搜尋並選擇頁面。
2. 修改頁面標題、搜尋摘要或編輯器內文字。
3. 按「儲存草稿」保留修改；此時正式網站不變。
4. 按「查看正式頁面」確認目前的正式內容。
5. 確認後按「發布到網站」。
6. 重新整理正式頁面查看最新內容。

切換頁面或關閉瀏覽器時，如果仍有未儲存修改，後台會顯示提醒。

## 上傳或更換圖片

新增圖片：

1. 在編輯器中把游標放在要插入圖片的位置。
2. 按「上傳圖片」並選擇 JPG、PNG 或 WebP。
3. 選擇裁切比例，拖曳圖片調整位置。
4. 使用「裁切縮放」調整畫面。
5. 設定頁面顯示寬度與圖片說明文字。
6. 按「裁切並套用圖片」。
7. 儲存草稿或發布。

更換或調整既有圖片：

1. 直接點選編輯器中的圖片，選取框會顯示。
2. 按「編輯選取圖片」。
3. 若只改尺寸或圖片說明，按「只調整顯示大小」。
4. 若要重新裁切，調整後按「裁切並套用圖片」。
5. 若要換圖，點選圖片後按「更換選取圖片」。

圖片說明文字應描述畫面內容，例如「士東路都更案建築外觀示意圖」，避免只填「照片」或檔名。

## 修改全站選單

1. 切換至「導覽選單」。
2. 修改選單名稱、第二行副標、顯示狀態或順序。
3. 按「儲存選單草稿」保留修改。
4. 按「發布選單」套用到全站。
5. 重新整理任一正式頁面確認結果。

連結頁面已固定保護，避免誤改網址造成失效。順序使用數字由小到大排列，建議以 10、20、30 的間距設定，方便日後插入項目。

## 儲存與發布的差別

| 按鈕 | 結果 |
| --- | --- |
| 儲存草稿 | 只有管理員看得到，正式網站不變 |
| 發布到網站 | 儲存草稿並更新正式網站內容 |
| 儲存選單草稿 | 只儲存選單修改，正式選單不變 |
| 發布選單 | 更新所有頁面的正式選單 |

## 使用注意事項

- 發布前先確認文字、圖片、連結與手機版閱讀效果。
- 不要一次貼入整份 Word 或 Google Docs 格式，可能帶入多餘樣式；建議分段貼上純文字再整理。
- 刪除或大量改寫內容前，先儲存現有畫面或確認 GitHub 靜態備援可復原。
- 圖片替換後，舊檔不會自動從 Storage 刪除。
- 若看到 Pinterest「儲存」按鈕，它來自使用者瀏覽器的 Pinterest 擴充功能，並非網站內容。

## 問題排除

登入連結一直回到登入畫面：確認使用同一個瀏覽器開啟 Email 連結，並檢查後台網址仍是 `/admin/`。

發布後看不到修改：先重新整理正式頁面；若仍未更新，登出再登入後重新發布，並把發生問題的頁面網址交給維護者檢查。

圖片無法上傳：改用 JPG、PNG 或 WebP，縮小檔案後再試，並確認網路連線正常。
